# Muscle & Ligament — Veterinary Pathology Website

A responsive, static educational website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP archive (if downloaded as a ZIP).
2. Open `index.html` in a modern browser.
3. Internet access is needed for Google Fonts and the externally hosted pathology image examples. The main layout, disease library and interactions work locally without a server.

## Files
- `index.html` — page structure and content sections
- `styles.css` — responsive visual design and category color system
- `diseases.js` — the 17 disease summaries and topic-specific references
- `app.js` — category filters, search, topic modal and navigation interactions
- `assets/images/hero-veterinary-anatomy.png` — generated 3D-style educational hero illustration

## Design system
- Global colors: Deep Navy `#142B45`, Teal `#19A6A0`, Soft White `#F4F7FA`
- Infectious: Coral `#DF7059`
- Inflammatory & Autoimmune: Violet `#8B70C9`
- Parasitic: Amber `#C99035`

## Image and academic notes
The 3D-style cow anatomy hero artwork is AI-generated for this project and is illustrative, not a diagnostic image. The pathology gallery uses externally hosted, source-linked images from published veterinary resources. Third-party images remain subject to their original licenses and permissions; check the source before redistributing or using them in a public commercial context. If an image fails to load, open its source link from the gallery card.

The disease entries are concise educational summaries, not a substitute for a specialist textbook or case-specific veterinary advice. Species relevance varies. Rheumatoid arthritis, systemic lupus erythematosus/Jaccoud arthropathy and inclusion body myositis are primarily human disease entities; the topic pages explicitly flag the limits of direct veterinary extrapolation. Confirm all statements and expand references with your course instructor before final academic submission.

## Hosting
Upload the contents of this folder (not the parent ZIP) to the public root of any static hosting provider, such as GitHub Pages, Netlify, Vercel static hosting or a conventional web host. No build step is required.
